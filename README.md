# Accounting Project

Uzbek tilidagi sodda buxgalteriya web-ilovasi. GitHub Pages orqali ishlaydi va server talab qilmaydi.

## Hozirgi imkoniyatlar
- Professional Dashboard
- Daromad va xarajat operatsiyalari
- Sana, kategoriya va izoh
- Operatsiyani tahrirlash va o‘chirish
- Qidiruv, tur/kategoriya/oy bo‘yicha filtr
- Jami daromad, xarajat va balans
- Kategoriyalar bo‘yicha qisqa ko‘rsatkich
- Hisobotlar bo‘limi
- Excel bilan ochiladigan UTF-8 CSV eksport
- Telefon, planshet va kompyuterga mos responsive dizayn
- Eski v2 ma’lumotlarini avtomatik saqlab qolish/migratsiya qilish
- Brauzer localStorage xotirasida saqlash

## Bo‘limlar
1. Dashboard — asosiy ko‘rsatkichlar va oxirgi operatsiyalar.
2. Operatsiyalar — barcha yozuvlar, qidiruv, filtr, tahrirlash va o‘chirish.
3. Hisobotlar — moliyaviy natija, CSV eksport va ma’lumotlarni boshqarish.

## Texnologiyalar
HTML, CSS va JavaScript. Hech qanday framework yoki backend talab qilinmaydi.

## Muhim
Bu hozircha o‘quv/mini hisob tizimi. Ma’lumotlar faqat ishlatilayotgan brauzerda saqlanadi. Keyingi katta bosqich uchun login, server va ma’lumotlar bazasi kerak bo‘ladi.
