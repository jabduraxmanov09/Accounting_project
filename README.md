# Accounting Project

Oddiy va mobil qurilmalarga mos daromad/xarajat hisoblash web-ilovasi.

## Imkoniyatlar
- Daromad va xarajat kiritish
- Jami daromad, jami xarajat va balansni avtomatik hisoblash
- Operatsiya sanasini saqlash
- Alohida operatsiyani o‘chirish yoki barcha ma’lumotlarni tozalash
- Ma’lumotlarni brauzerning localStorage xotirasida saqlash
- Telefon va kompyuter ekranlariga mos dizayn

## Ishlatish
`index.html` faylini brauzerda oching. Server yoki ma’lumotlar bazasi talab qilinmaydi.

> Eslatma: bu o‘quv loyihasi. Hozircha ma’lumotlar faqat foydalanuvchining brauzerida saqlanadi.
